# 🏠 House Price Analysis – King County, USA

## 🧩 Problem Statement
Understanding the factors that influence housing prices is essential for real estate decision-making.  
This project analyzes housing data to identify key variables affecting property value.

---

## 📊 Dataset
- **Name:** House sale prices for King County
- **Source:** (https://www.kaggle.com/harlfoxem/housesalesprediction?utm_medium=Exinfluencer&utm_source=Exinfluencer&utm_content=000026UJ&utm_term=10006555&utm_id=NA-SkillsNetwork-wwwcourseraorg-SkillsNetworkCoursesIBMDeveloperSkillsNetworkDA0101ENSkillsNetwork20235326-2022-01-01)
- **Format:** CSV

---

## ⚙️ Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Sklearn

---

## ⚙️ Methodology

### 1. Data Cleaning
- Handling missing values
- Data formatting and normalization

### 2. Exploratory Data Analysis (EDA)
- Distribution analysis of housing prices
- Correlation analysis between variables
- Identification of key drivers of price

### 3. Feature Analysis
- Evaluation of factors such as:
  - Square footage
  - Number of rooms
  - Location

### 4. Data Visualization
- Histograms and scatter plots
- Correlation heatmaps
- Trend visualization

---

## 📊 Key Insights
- Property size and location are primary drivers of price
- Strong correlation between square footage and price
- Certain features significantly increase property value

---

## 🚀 Outcome
This project demonstrates the ability to:
- Perform exploratory data analysis on real-world datasets
- Identify key variables influencing outcomes
- Generate insights applicable to business and decision-making contexts
